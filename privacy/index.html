《我的末世废土基地》隐私政策

更新日期：2026 年 9 月 26 日 生效日期：2026 年 9 月 26 日 版本：1.4
摘要：完整游戏存档默认保存在您的设备本地；中国大陆 Android 测试包在您同意本政策后使用 TapSDK 完成登录、实名认证/防沉迷、更新检查、账号活跃及玩法分析；TapTap H5 测试包在同一次隐私同意后使用宿主登录、玩家主动的云备份、激励广告、腾讯 RUM 游戏诊断，以及友盟 U-Mini H5 访问与首次出征流程统计。RUM 和友盟均不接收完整存档。当前不提供真实货币支付。

拾一工作室（以下简称“我们”）是《我的末世废土基地》的运营者。我们重视您的个人信息和隐私安全。本政策说明我们在您参与游戏封闭测试期间如何处理个人信息，以及您如何行使相关权利。

本地优先

完整游戏存档默认保存在设备内；只有在 TapTap H5 中由您主动操作云备份时，才会上传当前槽位存档。

账号与分析最小化

TapTap 登录仅申请 basic_info；原始 openId 仅在 Android 原生内存中交给 TapDB，不进入游戏页面、UI、存档或日志。

统一游戏诊断

TapTap H5 的游戏诊断与友盟流程统计在本政策的同一次选择中开启或停止，不另设独立选项。

H5 广告按需调用

只有您主动选择观看激励广告时才调用 TapTap H5 宿主能力；当前不提供真实货币购买。

一、适用范围与处理原则

本政策适用于《我的末世废土基地》封闭测试版本及其公开协议页面。我们遵循合法、正当、必要、诚信和最小化原则，仅在实现明确功能所必需的范围内处理信息。

本政策不适用于由第三方独立提供并直接控制的产品或服务。我们会在本政策中列明当前接入的第三方 SDK，并提供其隐私文件链接。

2.2 TapTap 登录、实名认证/防沉迷、数据分析与更新

在中国大陆 Android 测试包中，您同意本政策后，我们才会初始化 TapSDK。当前接入 TapSDK Core（含 TapDB 数据分析）、登录、合规认证和更新唤起模块，登录仅申请 basic_info 范围。

场景 可能处理的信息或权限 目的
TapTap 登录 openId、unionId；系统版本、设备型号、CPU、内存、网络类型、AndroidID、网络权限 使用 TapTap 账号登录并保障 SDK 兼容、定位问题
实名认证与防沉迷 TapTap 账号实名状态及合规结果、openId、系统与网络基本信息、网络状态 依法完成实名认证，执行年龄、时段和时长限制
TapDB 数据分析 openId（作为 TapDB 账号 ID）、TapDB 设备 ID、AndroidID 或随机 UUID、IP 地址、设备型号与厂商、操作系统及版本、时区、网络状态、应用标识、版本和渠道；应用启动、前台游玩时长；出征、搜索、战斗、结算和建筑升级的汇总行为数据 统计设备活跃、账号活跃、游玩时长和核心玩法使用情况，改进游戏体验

合规认证成功后，游戏会在 Android 原生层将原始 openId 设为 TapDB 的 user_id。该操作会生成 TapDB 内置的账号登录事件，并用于派生去重的账号日活数据。每次应用回到前台可重新绑定账号；切换账号、合规失败或受限、撤回同意及退出时会清除 SDK 当前账号标识。

自定义玩法事件仅在游戏规则变更成功且即时存档成功后发送，包含区域、难度、房间类型、战斗类型、敌人等级、结果、时长、人数、次数、数量、行动价值、建筑类型和游戏日等汇总字段。我们不通过这些事件发送角色、任务、实例或物品 ID，不发送名称、物品清单、完整存档、资源明细或玩家输入。

原始 openId 仅保存在 Android 原生内存中并直接交给 TapDB；TapTap Access Token、openId 或 unionId 不会传入游戏 WebView、UI、普通游戏存档或日志。我们只根据 TapTap 返回的“允许进入”或受限原因执行游戏准入，不获取或保存您的真实姓名和身份证号码。

TapSDK 由易玩（上海）网络科技有限公司提供。TapTap 对上述信息的独立处理规则请见 《TapSDK 隐私政策》。

2.3 TapTap H5 平台能力、腾讯 RUM 诊断与友盟统计

在 TapTap H5 测试包中，您同意本政策后，游戏才会通过宿主完成登录；只有您主动使用时，才会调用云备份或激励广告能力。

为排查游戏故障并优化玩家体验，我们在您同意本政策后启用腾讯云 RUM 游戏诊断。不同意或撤回同意后，H5 平台服务和 RUM 将停止运行。

启用后可能处理：

  • 程序错误及排查故障所需的有限上下文；
  • 广告流程状态，以及存档、操作等待和进入游戏等过程的耗时与存档大小范围；
  • 应用版本及设备、系统、网络等运行环境信息。

RUM 不接收完整游戏存档、存档身份、槽位、玩家输入或账号标识，也不用于页面访问分析或内存监控。腾讯云公开说明显示，RUM 原始错误和日志通常保留 30 天，汇总指标可能保留 90 天。

该服务由腾讯科技（深圳）有限公司提供，境内版本使用中国境内上报节点。详见 《前端性能监控 SDK 隐私保护协议》。

为了解新玩家从登录到首次出征的流程，并统计 H5 访问、新增、活跃与留存，我们在您同意本政策且 TapTap H5 授权登录成功后才加载友盟 U-Mini H5 统计脚本。统计事件包括登录成功、存档槽位准备完成、进入游戏、打开出征准备及出征成功；我们同时发送应用版本，以及进入游戏时“新建存档”或“继续存档”的类别。

友盟可能通过浏览器 Cookie 标识区分访客，并在访问和上报过程中处理 IP 地址、浏览器、设备及操作系统、网络环境、访问时间、页面访问和上述汇总行为信息。我们不向友盟发送 TapTap openId、unionId、存档 ID、完整存档、角色或物品明细、玩家输入。清除或限制 Cookie 可能影响同一访客的留存统计。撤回本政策同意后，游戏不再发送新的友盟统计事件。

该服务由友盟同欣（北京）科技有限公司提供。详见 《友盟+隐私政策》。

2.4 协议网站访问日志

当前公开协议网站由 GitHub Pages 提供 HTTPS 静态托管。GitHub 会为安全目的记录并保存访问者的 IP 地址；其他访问与服务信息的处理规则见 《GitHub 隐私声明》。我们不在这些页面中放置广告、分析脚本或自有 Cookie。

五、信息共享、转让与公开披露

除本政策已说明的第三方 SDK 处理、取得您的单独同意或法律法规另有要求外，我们不会出售、出租或向其他第三方提供您的个人信息。

如发生合并、分立、资产转让或运营主体变更并涉及个人信息转移，我们将依法告知接收方信息并要求其继续履行个人信息保护义务。

六、信息存储与保护

  1. 游戏业务存档、随机本地设备标识和同意记录保存在您的设备本地，直至您清除应用数据或卸载应用。
  2. TapSDK（包括 TapDB）、腾讯 RUM 与友盟 U-Mini H5 处理的信息由相应服务商按其隐私文件保存和保护。TapTap 表示仅在实现处理目的所必需的最短时间内保留，超期后删除或匿名化，法律法规另有要求的除外。
  3. 我们采用最小权限、访问控制、HTTPS 传输、限制日志字段等措施降低风险，但任何技术均无法保证绝对安全。
  4. 发生可能影响您权益的个人信息安全事件时，我们会依法采取补救措施并以合理方式告知。

七、您的权利

您依法享有查阅、复制、更正、补充、删除个人信息，以及撤回同意、投诉和要求解释本政策等权利。您可以：

  • 在游戏常驻“设置 → 其他 → 账号与协议”入口撤回统一的应用隐私同意；撤回后游戏会尝试保存并停止当前会话，同时停止对应平台服务、RUM 游戏诊断和友盟统计；Android 会请求退出，H5 会显示已停止页并由您通过宿主关闭；
  • 撤回或拒绝后，下次重新同意前不会初始化 TapSDK、TapTap H5 平台服务、RUM 或友盟统计；游戏诊断和友盟统计不设独立撤回开关；
  • 通过系统设置清除应用数据或卸载应用，删除本地存档、本地设备标识和同意记录；
  • 涉及 TapTap 账号、实名、账号活跃或玩法分析数据的请求，可同时依据 TapSDK 隐私政策向 TapTap 提出；
  • 通过下方邮箱向我们提出个人信息相关请求。为保障安全，我们可能要求您提供必要信息核验身份。

撤回同意不影响撤回前基于同意已经进行的信息处理。

八、未成年人保护

未成年人应在监护人指导下阅读本政策并使用游戏。未满 14 周岁的儿童应取得监护人同意后使用。我们通过 TapTap 合规认证落实实名认证和防沉迷限制，不直接获取或保存儿童的真实姓名、身份证号码。

如果监护人认为我们不当处理了未成年人的信息，请通过下方方式联系我们。核实后，我们将依法采取限制、删除或其他必要措施。

九、政策更新

当游戏功能、第三方 SDK、处理目的或适用法律发生变化时，我们可能更新本政策，并通过游戏内常驻协议入口、测试平台公告或其他合理方式提示。我们保留已同意玩家的已有同意记录，不因升级或政策变化重复要求确认；需要新增授权而无法沿用已有授权的能力，会在取得所需授权前暂停对该用户启用。

1.2 版补充 TapTap H5 登录、手动云备份和激励广告边界，并将腾讯 RUM 诊断纳入统一隐私同意。
